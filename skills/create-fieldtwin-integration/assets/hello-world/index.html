How to serve your integration
Option A — GitHub Pages or any HTTPS static host (simplest)

Push this file to GitHub and enable GitHub Pages. You get a permanent HTTPS URL that works from any network.

Best for: single-page integrations, demos, sharing.

Option B — localhost (active development only)

Run npx serve . or python3 -m http.server 3000 and register http://localhost:PORT as the integration URL.

An HTTPS FieldTwin blocks an http:// page as mixed content. For local testing only, in Chrome:
  1. Open FieldTwin, click the icon left of the URL bar → Site settings.
  2. Set Insecure content to Allow, then reload FieldTwin.
  3. Set it back to Block when you finish. For teammates, use HTTPS (Option A or a tunnel such as ngrok).
In FieldTwin: Admin → Integrations → Create New Tab

Enable Use GET verb and Do not pass arguments in URL. A static page cannot answer FieldTwin's default POST.
